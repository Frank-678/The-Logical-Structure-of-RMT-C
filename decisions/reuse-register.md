# 借鉴、适配、暂缓与否决记录

“否决”指不适用于当前RMTC任务或证据不足，不表示在原游戏中无效。证据定位见六集报告和snippets清单。

| ID | 方案 | 处理 | 依据与改造 |
|---|---|---|---|
| C01 | 圈地收益/闭环耗时 | 借鉴评价方法 | RMTC换成预期计分/路径及行动成本，不能搬轨迹规则 |
| C02 | 炸弹人时间展开可生存集合 | 适配 | 用RMTC事件窗口、攻击先行时序、局部未知信息 |
| C03 | 夺旗任务生成与联合分配 | 部分借鉴 | 目标评价可用；每队一机器人，无三角色分配问题 |
| C04 | 夺旗边移动边攻击 | 否决照搬 | RMTC每Tick仅一个动作，且攻击在移动前 |
| C05 | 全图最短路/全敌人真值 | 否决依赖前提 | RMTC只有局部视野；分开未知与历史观测 |
| C06 | 追敌旗手/击杀奖励权重 | 否决原值 | CTF只交旗得分；RMTC有有效伤害与封顶 |
| C07 | 多情景对手预测 | 适配 | 预测是概率/假设，不能把敌人上一动作当承诺 |
| C08 | 外交的身份/条约推理 | 暂缓直接实现 | RMTC无外交接口；保留事实/声明/预测分离习惯 |
| C09 | 仓储增量缓存与精确回退 | 借鉴工程机制 | 先必要条件，再昂贵寻路；失效条件写清 |
| C10 | 从终点反向BFS必定等价 | 否决无条件使用 | 上游被封起点可离开导致距离非对称；RMTC也应逐项检查 |
| C11 | 坦克权威step和候选矩阵 | 适配 | 自建RMTC单步规则模型；未知信息用情景，非全局真值 |
| C12 | 更深搜索必然更强 | 否决 | 模型误差、预算与候选质量可能主导；需配对测试 |
| C13 | 内嵌神经网络权重 | 否决 | RMTC禁止本地模型，单CPP也可能包含模型 |
| C14 | 单榜分数跨集比较模型 | 否决 | 计分、对手池、渠道、机器、时间/重赛条件不同 |
| C15 | 最终版总比中间版强 | 否决 | 上游版本演化反例；保留最佳与留出集 |
| C16 | fast模式成绩代表正式稳定 | 否决 | Tank fast不执行正式CPU超时处罚 |
| C17 | 两个独立榜单直接相减当进步 | 否决 | 需要同一对手池或联合拟合 |
| C18 | 仅平均总分评测 | 否决 | 需资源/伤害/任务资格、无效动作及事件失败分项 |

采用顺序：规则不变量→稳定基线→任务评价→准确局部推演→有限对手情景→必要时再增加搜索。来源借鉴不等于已经证明RMTC效果；数值权重不直接复制。
