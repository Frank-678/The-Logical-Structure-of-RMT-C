# v1.1对外部方法迁移的影响

当前RMTC依据[ANALYSIS规则迁移](https://github.com/Frank-678/The-Logical-Structure-of-RMT-C/blob/ANALYSIS/docs/11-v1.1-rule-migration.md)及其中引用的三份新PDF。meow-ai-arena仍固定原提交，六集原游戏规则与数据不因RMTC更新而改变。

D=max(0,旧D+本Tick实际攻击贡献+击杀奖励−60×死亡次数)，对抗15×min(D/500,1)。致死批次正贡献队伍去重均分每名死者60，反伤/辣椒损血不算普通攻击贡献但可获得奖励，爆炸/分裂死亡仅扣罚。

| 外部方法 | 保留 | v1.1需要改造 |
|---|---|---|
| 圈地兑现时间 | 路程与机会成本 | 死亡扣D；资源/任务保留不等于所有分都保留 |
| 炸弹人生存集合 | 按Tick预测危险与退路 | RMTC先攻后移、同批辣椒及死亡惩罚；不可搬原生存计分 |
| 夺旗追击/对手预测 | 能否到达、阻止对手的估计 | CTF只交旗得分；RMTC奖励看致死批次，不给历史攻击者 |
| 外交事实/声明区分 | 已知、推测与外部话语分开 | 群预告不能覆盖正式v1.1；不能把分奖理解成可串通互刷 |
| 仓储缓存修复 | 明确缓存有效与失效条件 | D不单调、满分可跌落；依赖旧分数前提的候选必须重评 |
| 坦克精确step | 小而准的状态转移 | 比例损血、队伍去重均奖、反伤/辣椒分批、先加后扣、存活任务 |

配对评测增加攻击贡献、奖励、扣除、当前D、对抗分、完成ID的分项。控制直接用公开score.effective_damage，不在官方值上二次加减。本地模型只用于评价，内部裁判记录仅供人工复核。超额D有缓冲与同分价值，不能沿用“曾满分就永久关闭战斗”的缓存策略。权重和风险阈值仍待同地图/席位/对手实验，不把六集榜单说成RMTC胜率证明。
