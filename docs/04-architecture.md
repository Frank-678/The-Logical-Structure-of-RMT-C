## 模块与契约

| 模块 | 输入→输出 | 必须满足 |
|---|---|---|
| ROS接入 | 公开话题→规范化观测 | 按正式QoS；校验session/tick；深度1避免旧感知积压 |
| 世界记忆 | 自己绝对坐标+实体相对图→带时效地图 | unknown≠empty；坐标以观测为准；实体同格边界 |
| 复活状态 | 初始出生点+已知墙/占据→可能落点 | 单独实现曼哈顿逐层枚举；障碍不截断搜索；按席位更新占据；缺少全图时保留不确定性，最终采用self.position（CHAT-01） |
| 事件接入/AI | 公告→结构化效果提案 | 公告去重但同Tick多公告不丢；官方调用有真实证据 |
| 效果状态 | 校验提案→有效时间区间 | session隔离；绝对tick到期；跨死亡不重置期限 |
| 任务规划 | missions+资源/伤害进度→目标候选 | 不写死练习目标；考虑封顶与任务资格 |
| 动作评价 | 局部状态+目标→MOVE/ATTACK/DEFEND/WAIT | 按攻击先于移动推演；当前占据和多人冲突 |
| 执行器 | 已选动作→公开动作话题 | 同Tick规划不推进两次；仅发本场合法动作 |
| 日志/回放 | 观测、选择、反馈→证据 | 分项得分、无效原因、模型延迟和资格分开记录 |

## 跨模块关键规则

每份观测和异步任务都带session_id；新session清旧观测推断、目标、缓存和事件。恢复时可重发同Tick缓存动作，但不能把路径步骤推进两次。执行前再做合法性过滤；最后一条合法候选的规则与“每Tick至多发布一次”的稳健默认分开记录。

AI事件提案建议含event_id、源文本哈希、类型、几何区域、触发方式、开始/结束tick、状态变化和未知项；这只是本地设计schema，不能冒称官方返回格式。格式正确不代表语义正确，校验失败时保留不确定性并选安全本地动作。不能用正则替代规则要求的语义理解。

初版不引入神经网络、不依赖观赛全图、不使用内部话题、不读取score.json或练习事件真值。本地算法可以BFS/Dijkstra、手写候选评分和有限步推演。没有全局信息时，精确模拟只对已知局部和明确规则成立，未知对手动作应按情景估计。

复活选点的逐层枚举与普通避障寻路分别建模；不能沿用“遇到障碍不展开”的移动搜索。方向映射、同距离完整顺序、同批复活占据更新及未决边界见[新增澄清](10-rule-clarifications-2026-10-21.md)。

## 实现顺序

接入与WAIT/MOVE基线→真实回执→地图记忆→任务与资源策略→官方AI异步理解与资格→时序精确的攻击防御→事件效果→小规模搜索。每一步有对应验证证据后才合并到最佳候选。
