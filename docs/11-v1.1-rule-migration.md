## 记账与结算

```text
D_t = max(0, D_(t-1) + 本Tick实际攻击贡献 + 击杀奖励 - 60*本Tick死亡次数)
S2  = 30*min(R/120,1) + 15*min(D_t/500,1) + 5*M
```

先按剩余HP比例分摊实际损血，再区分普通攻击贡献与反伤/辣椒损血；击杀奖励按合格队伍个数均分，不能按伤害比例分奖。同队多个贡献只占一份。每名死者独立形成奖励池。

完整顺序：清理/激活事件→事件死亡及分裂强制WAIT→固化动作/防御→移动前同时攻击/反伤，分摊贡献、分奖和死亡→存活者统一移动→同Tick辣椒统一伤害、分奖和死亡→存活者堡垒驻留与回血→全部攻击贡献和奖励入账后扣死亡惩罚→存活者采集/任务检查及普通复活/保护倒计时→下一Tick。普通战斗已击毁的车不能再产生同Tick辣椒击杀奖励。

感知score.effective_damage已完成上述结算，直接使用最新值，不再自行加60或扣60。D下降不能当成旧帧丢弃；乱序判断仍依赖session_id与tick。本地规则模型用于候选评价和对照，不能从D变化反推出所有不可见击杀/死亡事实。

## 主要trade-off（推论，待配对实验）

未封顶时每点D对应0.03分，普通20点实际伤害0.6分；普通资源仍2.5分、高价值资源仍5分。独享60奖励最多1.8分；一次死亡的即时对抗分损失介于0和1.8分，另有复活等待、赶路、资源机会和对手击杀收益。无新增时，直接损失为15×[min(D/500,1)−min(max(0,D−60)/500,1)]，不是每死一次一律扣1.8总分。

追击需分别估计本Tick可得攻击贡献、进入致死批次的概率、预计分奖人数、自己被击毁的概率，以及错过资源/任务的成本。先前打掉大量HP不保证分到击杀奖；致死批次少量正伤害可能均分，但局部信息不足时不能假定别人必然集火。普通攻击先于移动，移动仍无法躲掉本Tick已结算攻击。

反伤期间防御可能获得击杀奖；辣椒踩点也可能带来奖励，但要计入被其他火线命中和自身死亡扣除。爆炸与分裂没有击杀补偿，规避价值增加。未封顶的资源相对普通换血更值钱，但不能据此推导永远只采集。

D达到500后即时增分斜率为0，超额D却可缓冲以后扣除并参与同分。候选评价应使用当前D，不能缓存“曾满分所以永久停止战斗”。风险偏好随D、剩余资源、任务状态、剩余Tick和晋级目标变化；权重须在同地图/席位/对手配对实验中选择。
