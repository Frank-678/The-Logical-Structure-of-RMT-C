- 计分仍为30min(R/120,1)+15min(D/500,1)+5M；D先加实际攻击贡献和击杀奖励、再按每次死亡扣60，最低0，允许小数/下降/超过500，超过部分用于同分。任务完成保留，伤害任务只对存活车判定。
- 攻击与死亡仍在移动前结算；普通攻击只打方向1–2格最近敌车；近处出生保护仍挡住后方目标；正常攻击同Tick同时结算。
- 反伤/辣椒损血不计普通攻击贡献，致死合格队伍可分60奖励；环境爆炸/分裂死亡不发击杀奖励。此前[计分与战术推导](14-tactical-and-message-design.md)无需因为版本号重算。
- 堡垒标准3×3、50Tick、连续驻留10Tick；授予增益在战斗后，不追溯当Tick攻击；无双攻击以车自身为中心5×5。§8.1仍规定具体场次数值看公告，不能把标准值写死到所有练习。
- 官方LLM理解随机事件、本场正式AI成功资格、本地小模型禁用、封存Prompt/参数及登记策略切换、真实回执均不变。

## 复活算法的准确边界

初始出生点O可用则优先；否则按曼哈顿距离逐层，方向优先上→右→下→左。静态墙和生效分裂墙只排除落点，不截断向更远坐标的搜索；资源格可落点，存活车辆占格不可落点。多车同批按席位顺序放置，后车看到前车已占用的新落点。

工程建议：把复活候选枚举与寻路分开。寻路求机器人能走到哪里，复活只找几何最近合法落点，不能沿用墙不可展开的搜索。更远层的队列去重/枚举细节应按原文顺序实现并对照引擎；本版仍未给出完整伪代码，也没有规定所有格都不可用的后备行为。部分视野下只预测可能集合，实际落点采用下一感知self.position。

本版没有新增“世界分裂复活2Tick保护”的独立明文句子；该补充仍定位QA-02 C6/D6。§7已有普通保护条款及分裂立即复活条款，§8.6仍明确分裂无视保护、立即复活仍扣60D，不能把这些误说成v1.2取消死亡惩罚或取消保护。

## 堡垒区域状态与测试设计

设计建议/待对战：保存来源场次、公告标识/哈希、LLM解释的区域及起止Tick、校验状态。公告确定新区域后，驻留候选、路径和威胁图使用该区域；换场清理。尚不确定的位置不以“通常在中心”当事实执行占领计划。公开任务目标[12,12]与堡垒范围是不同对象，不能因常见重合便合并缓存。

新增验收队列：常见九格堡垒、偏移堡垒、同地图不同公告、不同尺寸地图、多个公告同Tick、旧场公告重放、LLM结果延迟/无效、区域与任务目标不重合。复活继续采用[既有R01–R12](10-rule-clarifications-2026-10-21.md)并核验源升级为RULES-03 §7。这些用例尚未跑过新引擎。

## 交付优先级与来源限制

1. 复核当前参赛代码是否写死堡垒坐标；改为依据合法公告和LLM解释的本地效果状态，再做场景测试。
2. 复核复活候选算法是否把墙当作不可扩展路径，检查A→D占位更新；联调以真实坐标回执验收。
3. 优先准备可运行代码仓库、环境/启动说明、语雀报告、真实测试截图/录屏及路径版本一致性；容器镜像降为可选工程交付。
