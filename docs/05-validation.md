# 验证方案与证据要求

2026-10-27当前规则为RULES-03 v1.2：[迁移与行动](16-v1.2-rule-migration.md)。堡垒范围以当场公告为准；复活选点已写入正式规则；语言不限，镜像不再必交。旧版本记录保留作历史依据。

[新增地图编辑器与现场通知](15-map-editor-and-onsite-addendum.md)：原件、导出兼容性、13项逻辑检查和配置验证；现场替补与切换仍按封存规则执行。

[战术与消息处理详解](14-tactical-and-message-design.md)：汇总攻击/移动、辣椒、堡垒、计分及暂停恢复；验收用例均待执行。

v1.1优先验收：单杀/互杀、过量比例分摊、去重均奖、旧攻击者排除、反伤、同批辣椒、环境死亡、满分跌落和伤害任务锁存。[24项算术核对](../checks/releases/v1.1/scoring-examples.json)通过只证明规则例子，裁判运行仍待验证。

当前已完成的是文件/哈希/静态协议核对；尚未完成ROS 2运行、真实AI、自有bot联调或策略胜率实验。

| 层次 | 关键场景 | 通过证据 |
|---|---|---|
| 接入 | 自有程序收感知、发动作、下Tick反馈 | 同一session的三段日志和录屏；参考车不算 |
| 坐标 | 每实体9×9图、同格、边界、unknown | 转换结果与公开观测逐项一致 |
| Tick | 重复感知、旧Tick、重开session | 不重复推进规划，不发送旧场次动作 |
| 移动 | 占据、换位、跟进、抢同空格 | 与正式规则预期一致，记录无效动作 |
| 攻防 | 移动前受击、近目标挡远目标、墙不挡普通攻击 | 实际last_action/HP反馈与预期一致 |
| 死亡 | 复活等待、保护解除、效果跨死亡 | tick级状态轨迹；资源/完成任务保留；D按v1.1先加后扣60、最低0，不在官方值上重复扣罚 |
| 复活选点 | 初始点/死亡点区分、曼哈顿同距、墙后落点、资源格、同批席位先后 | 按[CHAT-01对照用例R01–R12](10-rule-clarifications-2026-10-21.md)记录实际self.position；更远层顺序与无合法格行为不得臆造 |
| 事件 | 八类事件的触发与到期边界 | 规则标准和练习参数各自核对 |
| AI | 迟到、失败、429分类、重复公告、多公告 | 本场本席位真实成功证据；旧结果被拒 |
| 任务 | missions坐标变化、ID只计一次、AI资格 | 结构化任务状态与分项结算 |
| 策略 | 配对地图/座位/对手，多个未调参种子 | 分项分、晋级率、置信范围与失败回放 |
| 性能 | 慢模型、拥堵、断路、缓存失效 | 控制周期不中断，有合法兜底，无积压 |
| 现场网络 | 全队虚拟机、有线、实际主机与网口配置 | 自备网线完成自有程序DDS双向、动作回执与完整对局；SSH/网页通不算（CHAT-02） |

固定对照版本、候选版本和最佳已验证版本；测试种子/对手池/机器/并行数/规则版本都记录。调参集和验收集分开。统计单位按地图配对，不把同图换边结果当完全独立样本。

先看分项：资源、有效伤害、获资格任务、无效动作、超时、死亡机会损失、AI调用成功率和延迟。只有总分会掩盖任务资格缺失或某类事件时序错误。

回放定位失败→提出单一机制假设→修改→固定条件比较→留出集验收。没有显著改善时保留旧版；新版本编译更长、代码更多或局部样例更漂亮都不构成采用理由。
