# 规则基线与必须遵守的不变量

详表与原文定位见 [全部附件核读](01-source-review.md) §§4–8 和 [引用索引](../REFERENCES.md)。

| 机制 | 当前核对结论 | 来源 |
|---|---|---|
| 第一阶段 | 100 Tick ×100ms；资源200对应40分；用于种子，不与第二阶段相加 | RULES-01 §§3–4 |
| 第二阶段 | 最多4队，500 Tick ×500ms；资源30、有效伤害15、三任务15 | RULES-01 §§3–4、9–11 |
| 信息 | 自己绝对坐标；标准半径4；每实体单独9×9相对图，0不是已知空地 | PROTO-01 §§2–4 |
| 动作 | 每次结算一个 MOVE/ATTACK/DEFEND/WAIT；第一阶段仅MOVE/WAIT | RULES-01 §§5–7 |
| 占据 | 不能换位/跟进当前被占格；同空格争抢全失败 | RULES-01 §§5–7 |
| 普通攻击 | 移动前位置、方向1–2格最近敌车；墙不挡普通攻击 | RULES-01 §§5–7 |
| 死亡 | 已有资源、伤害、任务不扣；有复活等待和保护；效果绝对到期不顺延 | RULES-01 §§6–8 |
| 复活选点 | 以初始出生点算曼哈顿距离；按上→右→下→左逐层找合法格；障碍不截断搜索，资源格可落点；同批按A→D处理并更新占据 | CHAT-01，群内答疑；[细节与待测项](10-rule-clarifications-2026-10-21.md) |
| 模型 | 官方网关；事件交LLM理解；可本地算法执行；禁止本地模型 | RULES-01、PROTO-01 §§4–7 |
| 任务资格 | 本场本席位正式AI成功调用，才保留任务分和相应同分优势 | RULES-01 §§9–11 |

结算必须按：事件清理/激活→事件死亡→固化动作/设置防御→移动前攻击/死亡→存活者移动→入点事件→堡垒驻留/回血→采集/任务→下一Tick。

不要把“移动可能改善下一回合站位”写成“能躲掉本回合的攻击”。不要把最近一次 defending 当成本回合动作承诺。

八类事件的正式值/练习值逐项对照保存在 01-source-review.md §6；正式数值不能从练习配置硬编码推断。实际生效公告和模型理解结果须带来源、场次和到期Tick。

练习程序的源码可读部分与五个无源码 ELF 分开：manifest 通过只说明完整性，不能据此声称审查了封闭引擎实现。本机未运行 ROS 2，静态推断如 /healthz 路由缺失必须在目标环境实测。
