# 规则基线与必须遵守的不变量

2026-10-27当前规则为RULES-03 v1.2：[迁移与行动](16-v1.2-rule-migration.md)。堡垒范围以当场公告为准；复活选点已写入正式规则；语言不限，镜像不再必交。旧版本记录保留作历史依据。

对抗15×min(D/500,1)；D可下降、可小数、超过500不截断。每名死者60由致死批次正贡献队伍去重均分。反伤/辣椒损血不算普通攻击贡献，但可获击杀奖。伤害任务按调整后D且只检查存活者；完成ID保留。

当前基线RULES-03（规则v1.2）、PROTO-02和TUTORIAL-02（配套v1.1），见[迁移分析](16-v1.2-rule-migration.md)、[引用索引](../REFERENCES.md)；旧核读仅历史用途。

结算必须按：事件清理/激活→事件死亡→固化动作/设置防御→移动前攻击/死亡→存活者移动→入点事件→堡垒驻留/回血→全部贡献/奖励入账后扣死亡惩罚→存活者采集/任务→下一Tick。

不要把“移动可能改善下一回合站位”写成“能躲掉本回合的攻击”。不要把最近一次 defending 当成本回合动作承诺。

八类事件的正式值/练习值逐项对照保存在 01-source-review.md §6；正式数值不能从练习配置硬编码推断。实际生效公告和模型理解结果须带来源、场次和到期Tick。

练习程序的源码可读部分与五个无源码 ELF 分开：manifest 通过只说明完整性，不能据此声称审查了封闭引擎实现。本机未运行 ROS 2，静态推断如 /healthz 路由缺失必须在目标环境实测。
