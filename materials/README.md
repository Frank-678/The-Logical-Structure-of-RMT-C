# 材料总入口

原始文件统一使用稳定英文文件名，字节内容保持不变；原中文名、页数、SHA-256 和用途见 [catalog.json](catalog.json)。

- original/：六份原 PDF、转写 ZIP、程序发行 ZIP，共八个附件。
- extracted/：六份 PDF 全文文本。PDF 跨行表格或代码提取可能乱序，正式引用返回原 PDF 页码核对。
- transcripts/：两份既有转写文本及 DOCX 原件。ZIP 没有音频，本次没有执行语音转写。
- practice/rmtc_practice/：发行包展开后的完整练习程序（含五个原始 ELF），可读源码与配置未修改；版权和权限边界同发行材料。
- addenda/2026-10-21/：两张新增群内答疑截图原件及[可见文字转录](addenda/2026-10-21/chat-transcript.md)。复活选点与有线联调要求纳入分析；赛程重发与原PDF一致。收录日期不代替消息发布日期。

前三次任务用于学习准备，不把其中 API 训练要求自动套成正式比赛调用方式。练习配置与观赛管理功能仅用于人工调试，不作为机器人决策输入。
